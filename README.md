# Kana Trainer

Kana Trainer is a simple and smart web application for learning Japanese Hiragana and Katakana.  
It helps users quickly recognize kana characters through quizzes and spaced repetition learning.

## Features

- Learn Mode for studying all kana
- Quiz Mode with multiple choice questions
- Hiragana, Katakana, and Combined quizzes
- Smart learning algorithm (Hard characters appear more often)
- Spaced repetition system
- Mastered kana detection
- Progress tracking and stats
- 10-second quiz timer
- Mobile-friendly responsive design
- Installable PWA (Add to Home Screen)

## Technologies Used

- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
- LocalStorage
